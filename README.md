# Arch + Hyprland Setup Script

Acest script instalează rapid un mediu complet Hyprland pe Arch Linux,
inclusiv Waybar, Fish, PipeWire, Thunar, notificări, wallpaper daemon (awww)
și tema GTK Graphite.

## Ce instalează

- Hyprland (compositor Wayland)
- Waybar (bara de status)
- Kitty (terminal)
- Thunar (file manager)
- Mako (notificări)
- Wofi (launcher)
- PipeWire + WirePlumber (audio)
- Bluetooth
- AWWW (wallpaper daemon)
- Fish shell
- Yay (AUR helper)
- Graphite-Blue-Dark GTK theme
- Papirus icon theme
